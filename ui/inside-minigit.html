Inside minigit

minigit gives every piece of data a name made from the data itself — a fingerprint. This page shows, step by step, what the program does inside its .minigit folder.

Fingerprint = SHA-1 hash Cupboard = object store (.minigit/objects) File-content box = blob Folder-list box = tree Snapshot = commit Ready list = index Time travel = checkout

See what the C program did

Run the program in a folder first, for example:

minigit init
printf 'Hello World\n' > hello.txt
cp hello.txt copy.txt
minigit add .
minigit commit -m "First snapshot"
  1. Click the button below.
  2. Choose the project folder — the one that contains .minigit.
  3. Your browser may ask to "upload" the folder. Nothing leaves your computer; this page only reads it.

After loading, the cupboard, snapshots and pictures below show your real data. You can keep playing; nothing is written back to disk.

The fingerprint machine

SHA-1 of "blob <size>\0<text>"

Type anything. Each line is treated like a small file that holds that text. Change just one letter and watch the fingerprint change completely.
